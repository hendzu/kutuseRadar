# kütuseRadar – Planned Features

## Essential

- Koduleht
- Get leht
- Post leht
- Loo kasutaja
- Sisse ja välja logimis võime
- Get lehel eri toote/asukoha põhine otsing
- Post lehel saab sisestada asukoha + toote + hinna kui sisse loginud

## Non-Essential

- Asukohad kaardile / Google Maps integratsioon
- Post lehel saab panna pilid — võtame pildi pealt toote ja hinna (API 1) ning asukoha ja kellaaja (API 2)
- Võime vaadata ajas hinna muutust
- Post lehel adminil võimalik lisada asukohti
- Raadiuses hinna võrdlus
- Näitab kaardi peal hinda
